# @vibelevel/aura-ui

The presentational, auth-free viewer UI for **Open Aura** — the local app shell/sidebar plus the public, shareable surfaces, with zero auth/session coupling. It expects a **host application that provides the `/api/aura/*` endpoints** (the components fetch from relative URLs such as `/api/aura/leaderboard`, `/api/aura/session/{id}`, and `/api/aura/profile/{handle}/like`), uses `next/link`/`next/navigation`, and runs Tailwind CSS. Import the theme tokens once via `@vibelevel/aura-ui/styles/aura-theme.css` (it defines the `--vibecoder-*` variables, the `.vibecoder-ide` scope, and the `.vibecoder-panel` utility the components rely on). **Export surface:** components `AuraProfile`, `LocalAuraShell`, `AuraSidebar`, `AuraSessionList`, `PublicAuraShell`/`PublicAuraHeader`, `AuraLeaderboard`, `AuraRadar` (+ `RadarDimension`), plus supporting `InsightCard`/`InsightCardGrid`, `AuraGuide`, and `VibeLevelLogo`; the public types `Modality`, `Source`, `CardScope`, `CardClass`, `Card`, `DimensionScore`, `SessionSummary`, `ScoreResult`, `ProfileResponse`, `AuraLeaderboardEntry`, `AuraSidebarSummary`; and display helpers `AURA_LEVEL_COLORS`, `AURA_LEVELS`, `AURA_ARCHETYPES`, `AURA_DIMENSION_LABELS`, `dominantModality`, `formatTokens`, `getCardGuide`, `SOURCE_HOW`.
